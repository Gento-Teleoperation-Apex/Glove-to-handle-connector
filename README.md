# Product Overview

This product is designed for 3D printing.

## Hardware specification
- Hole diameter: M3
- Recommended fastener: M3 x 8 screw
## Assembly Notes
If needed, non-slip material can be added to the inner wall for better grip and stability.
Note: All hole sizes in this design follow the M3 standard, and M3 x 8 screws are recommended for assembly.
